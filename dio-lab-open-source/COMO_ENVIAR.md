# Como enviar sua contribuição

1. Faça o fork de https://github.com/digitalinnovationone/dio-lab-open-source
2. Clone o SEU fork e entre na pasta:
   git clone https://github.com/SEU_USERNAME/dio-lab-open-source.git
   cd dio-lab-open-source
3. Crie a branch:
   git checkout -b feat/community/SEU_USERNAME
4. Copie o arquivo `community/SEU_USERNAME.md` deste zip para a pasta `community/` do clone
   e RENOMEIE para o seu usuário do GitHub (exatamente igual, maiúsculas/minúsculas contam).
   Depois troque todo "SEU_USERNAME" dentro do arquivo pelo seu usuário.
5. Commit e push:
   git add community/SEU_USERNAME.md
   git commit -m "feat: add SEU_USERNAME profile"
   git push origin feat/community/SEU_USERNAME
6. No GitHub, abra o Pull Request do seu fork para o repositório original.
   O PR deve alterar SOMENTE community/SEU_USERNAME.md.
7. Na DIO, em "Entregar Projeto", envie o link do seu fork
   (https://github.com/SEU_USERNAME/dio-lab-open-source) e descreva:
   "Adicionei meu Profile README em community/SEU_USERNAME.md e abri PR para o repositório original."
